# Datasets

This repository contains **no third-party attack data**. The benchmark (`bench/attacks/`) can import public
prompt-injection datasets for testing, but you fetch them yourself; they are not redistributed here. The
cases under `bench/attacks/cases/` are written by this project (generated by `bench/attacks/own_build/` and
`bench/attacks/generators.py`).

Pins, sizes and hashes are in `bench/attacks/sources.json`. `fetch.py` checks every file's hash and refuses a
source whose `approved` flag is not `true`. Licences below were read on each official page on 2026-11-16;
check them again before you redistribute anything. Licence tags on Hugging Face cards are the uploader's own
statement.

Only the BIPIA text/code attack files and email contexts are listed in `sources.json`. Its table task data
(WikiTableQuestions, CC-BY-SA-4.0) and its QA and summarisation contexts (third-party licences) are skipped.

**Deliberately not used:** Tensor Trust (HumanCompatibleAI/tensor-trust-data). The data repository has no
licence file, and the SPML authors say its prompts are not licensed for distribution. It is marked
`approved: false` in `sources.json`.

## How to download

Python 3.10+. The parquet files (sources 1 and 2) need `pyarrow` in the importer's environment only; the guard
itself has no dependencies.

```
python -I bench/attacks/fetch.py --list
python -I bench/attacks/fetch.py --dest <new empty folder outside this repo> --source deepset-prompt-injections --source lakera-gandalf-ignore-instructions --source spml-chatbot-prompt-injection --source agentdojo --source bipia
python -I -B bench/attacks/import_public.py --cache <that folder>
```

Run `python bench/attacks/fetch.py --help` and `import_public.py --help` for all options. Imported cases are
written outside the repo; publish case ids and results, not the dataset text. If you redistribute any of
these datasets, keep each one's licence text and cite its authors.
